## Repository Structure

- `frontend/`: React + TypeScript frontend application.
- `backend/`: FastAPI Python backend application.
- `ml/`: Machine learning model training scripts, notebooks, and serialized artifacts.
- `data/`: Raw and processed datasets (excluded from Git).
- `docs/`: Project documentation, SOW, diagrams, and reports.
- `tests/`: Root-level integration or end-to-end tests.
